Motivational Texts

This page is still under construction too, I'm just working things out.

A text generator that pulls texts from an array of quotes said by people I know, as well as ones that I've written myself. This project has been made using multiple engines, in order to test and learn better coding skills. Currently, this generator exists in Java and Godot. There's hope to create it in app form and webapp form.

This idea was coded from a simple request from a request from a friend: “Can you code a lil widget/app for a phone somehow that has motivation short texts that show up. Kinda like Co-star, but not focused on zodiac stuff. Just, like, motivational stuff. Like, the little widget for Co-Star today says "No self-denial, today" and that's been keepin me perky fr.” Because I've coded a few generators over time, I decided to jump right into working on the code.
